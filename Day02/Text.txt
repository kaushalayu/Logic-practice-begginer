STANDARD TEMPLATE LIBRARY (STL) IN C++

1. Introduction

STL stands for Standard Template Library. It is a part of C++ that provides ready-made classes and functions for performing common programming tasks.

Suppose we want to store a list of numbers, sort them, or search for a particular number. We can write the complete logic ourselves, but STL provides functions and containers that make these tasks much easier.

STL is useful because it saves time, reduces code length, and makes programs easier to understand. It is also widely used in data structures, algorithms, and competitive programming.

2. Main Components of STL

STL mainly has four important components:

Containers: Used to store data, such as vectors, lists, stacks, and queues.
Algorithms: Used to perform operations such as sorting, searching, and reversing.
Iterators: Used to access and move through the elements of containers.
Function Objects: Used to define operations that can be passed to algorithms.

These components work together to make C++ programming more convenient.

3. Vector in STL

A vector is similar to an array, but its size can change automatically when elements are added or removed. It is useful when we need to store a collection of values and do not know the exact size in advance.

Example 1: Adding and Displaying Elements
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {10, 20, 30};

    v.push_back(40);
    v.push_back(50);

    cout << "Vector elements: ";

    for (int x : v) {
        cout << x << " ";
    }

    cout << "\nTotal elements: " << v.size();

    return 0;
}

Output
Vector elements: 10 20 30 40 50
Total elements: 5

Explanation
vector<int> creates a vector that stores integer values.
push_back() adds a new element at the end.
The for loop prints each element.
size() returns the total number of elements currently stored.

In this example, the vector initially contains three elements. After adding two more values, its size becomes five.

4. List in STL

A list is a container that stores elements in sequence. It allows efficient insertion and deletion at different positions when an iterator is available. Unlike a vector, it does not support direct indexing with square brackets.

Example 2: Inserting Elements into a List
#include <iostream>
#include <list>
using namespace std;

int main() {
    list<int> numbers = {20, 30, 40};

    numbers.push_front(10);
    numbers.push_back(50);

    cout << "List elements: ";

    for (int x : numbers) {
        cout << x << " ";
    }

    return 0;
}

Output
List elements: 10 20 30 40 50

Explanation
list<int> creates a list of integers.
push_front(10) adds 10 at the beginning.
push_back(50) adds 50 at the end.
The loop displays all elements in order.

Lists are useful when frequent insertions and deletions are required. However, accessing an element by its numerical position is slower than with a vector.

5. Stack in STL

A stack follows the LIFO principle, which stands for Last In, First Out. This means the element inserted last is removed first.

A simple real-life example is a stack of plates. The plate placed on top is the first plate we take out.

Example 3: Push and Pop Operations
#include <iostream>
#include <stack>
using namespace std;

int main() {
    stack<int> s;

    s.push(10);
    s.push(20);
    s.push(30);

    cout << "Top element: " << s.top() << endl;

    s.pop();

    cout << "After pop: " << s.top() << endl;

    cout << "Stack size: " << s.size();

    return 0;
}

Output
Top element: 30
After pop: 20
Stack size: 2

Explanation
push() inserts an element into the stack.
top() returns the element at the top.
pop() removes the top element.
size() returns the number of elements.

Initially, 30 is at the top because it was inserted last. After removing 30, the top element becomes 20.

Note: The pop() function removes an element but does not return its value.

6. Queue in STL

A queue follows the FIFO principle, which stands for First In, First Out. The element inserted first is removed first.

For example, people standing in a ticket counter line are generally served in the order in which they arrive.

Example 4: Queue Operations
#include <iostream>
#include <queue>
using namespace std;

int main() {
    queue<int> q;

    q.push(100);
    q.push(200);
    q.push(300);

    cout << "Front element: " << q.front() << endl;

    q.pop();

    cout << "New front: " << q.front() << endl;
    cout << "Queue size: " << q.size();

    return 0;
}

Output
Front element: 100
New front: 200
Queue size: 2

Explanation
push() adds an element at the back of the queue.
front() returns the first element.
pop() removes the first element.
size() gives the total number of elements.

After inserting three elements, 100 is at the front. When it is removed, 200 becomes the new front.

7. Algorithms in STL

STL provides many ready-made algorithms that can be used with containers. Most of the common algorithms are available in the <algorithm> header file.

Some important algorithms are:

sort() – Sorts elements.
reverse() – Reverses the order of elements.
find() – Searches for a value.
count() – Counts the occurrences of a value.
max_element() – Finds the largest element.
min_element() – Finds the smallest element.
Example 5: Sorting Numbers
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> v = {50, 10, 40, 20, 30};

    sort(v.begin(), v.end());

    cout << "Sorted numbers: ";

    for (int x : v) {
        cout << x << " ";
    }

    return 0;
}

Output
Sorted numbers: 10 20 30 40 50

Explanation
sort() arranges the numbers in ascending order by default.
begin() refers to the first element.
end() refers to the position just after the last element.

The original order of the numbers is changed to ascending order.

Example 6: Searching for an Element
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> v = {10, 20, 30, 40, 50};

    auto it = find(v.begin(), v.end(), 30);

    if (it != v.end()) {
        cout << "Element found: " << *it;
    } else {
        cout << "Element not found";
    }

    return 0;
}

Output
Element found: 30

Explanation
find() searches for the given value in the specified range.
If the element is found, it returns an iterator pointing to that element.
If it is not found, it returns v.end().
*it gives the value pointed to by the iterator.

In this example, 30 is present in the vector, so the program displays that the element has been found.

8. Iterators in STL

Iterators are used to access the elements of STL containers. They work somewhat like pointers and allow us to move through a container one element at a time.

Example 7: Using an Iterator
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {5, 10, 15, 20};

    vector<int>::iterator it;

    cout << "Elements: ";

    for (it = v.begin(); it != v.end(); ++it) {
        cout << *it << " ";
    }

    return 0;
}

Output
Elements: 5 10 15 20

Explanation
vector<int>::iterator declares an iterator for an integer vector.
begin() points to the first element.
end() represents the position after the last element.
++it moves the iterator forward.
*it accesses the current element.

Iterators make it possible to process container elements without using numerical indexes.

9. Function Objects in STL

Function objects, also called functors, are objects that can be called like functions. STL provides standard function objects that can change how algorithms behave.

For example, greater<int>() can be used with sort() to arrange integers in descending order.

Example 8: Sorting in Descending Order
#include <iostream>
#include <vector>
#include <algorithm>
#include <functional>
using namespace std;

int main() {
    vector<int> v = {10, 40, 20, 50, 30};

    sort(v.begin(), v.end(), greater<int>());

    cout << "Descending order: ";

    for (int x : v) {
        cout << x << " ";
    }

    return 0;
}

Output
Descending order: 50 40 30 20 10

Explanation

The greater<int>() function object tells sort() to arrange the integers from largest to smallest. Without it, sort() arranges the numbers in ascending order by default.

10. Advantages of STL

STL provides several advantages in C++ programming:

Saves time: Ready-made functions reduce the need to write everything from scratch.
Less code: Complex operations can often be completed in a few lines.
Code reusability: The same containers and algorithms can be used in different programs.
Efficient performance: STL provides implementations designed for efficient operations.
Easy data management: Different containers are available for different requirements.
Useful in competitive programming: STL helps programmers focus on solving problems instead of repeatedly implementing basic operations.
11. Applications of STL

STL is used in many areas of programming.

Vectors are used to store dynamic collections of data.
Stacks are useful in expression evaluation, undo operations, and function-call management.
Queues are used in scheduling and breadth-first search.
Sorting algorithms are used to arrange records and numbers.
Searching algorithms help locate particular elements.
Iterators are useful for traversing container elements.

STL is also widely used in data structures and algorithms because it provides standard, reusable components.

12. Conclusion

The Standard Template Library is an important part of C++. It makes programming easier by providing containers, algorithms, iterators, and function objects.

By using STL, programmers can write shorter and more organized code without implementing every operation themselves. Understanding STL is helpful for learning data structures, solving programming problems, and developing efficient C++ applications.
